MODIFIED FONT NOTICE
HydraMaterialSymbolsRounded-Filled.ttf is a static instance generated by Hydra
Shell contributors using FontTools 4.68.0 varLib.instancer at FILL=1, GRAD=0,
opsz=24, wght=400. All original glyphs, Unicode mappings and ligatures are kept;
this is the full font repertoire, not a settings-only subset. Static instancing
reduces the original 15,235,612-byte variable font to 1,828,100 bytes. The font's
family, subfamily, unique ID, full name, PostScript name and typographic names
are renamed to Hydra Material Symbols Rounded / Regular (PostScript name
HydraMaterialSymbolsRounded-Filled), preventing dependency on or collisions
with an installed Material Symbols font. The upstream copyright is retained.
The font's Apache-2.0 license is unchanged. No font installation or network
connection is needed at runtime.

Reproduction command (Python with fonttools==4.68.0; run in the destination
directory). The fixed OpenType modification timestamp preserves the bundled
asset's generation timestamp rather than introducing the current wall clock.
No subsetting is performed.

python3 - <<'PY'
import hashlib
import io
import urllib.request
from fontTools.ttLib import TTFont
from fontTools.varLib.instancer import instantiateVariableFont

revision = "10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7"
url = (
    "https://raw.githubusercontent.com/google/material-design-icons/"
    + revision
    + "/variablefont/MaterialSymbolsRounded%5BFILL%2CGRAD%2Copsz%2Cwght%5D.ttf"
)
source = urllib.request.urlopen(url).read()
assert hashlib.sha256(source).hexdigest() == (
    "7e74e36533ccee12c2b81e75bfcf3ccf123d3bb7e7e46d65d94445f23db0c97c"
)
font = instantiateVariableFont(
    TTFont(io.BytesIO(source)),
    {"FILL": 1, "GRAD": 0, "opsz": 24, "wght": 400},
    inplace=False,
)
family = "Hydra Material Symbols Rounded"
names = {
    1: family,
    2: "Regular",
    3: "HydraMaterialSymbolsRoundedFilled-" + revision[:12],
    4: family + " Filled",
    6: "HydraMaterialSymbolsRounded-Filled",
    16: family,
    17: "Regular",
}
for record in font["name"].names:
    if record.nameID in names:
        record.string = names[record.nameID].encode(record.getEncoding())
font.recalcTimestamp = False
font["head"].modified = 3876570200
font.save("HydraMaterialSymbolsRounded-Filled.ttf")
PY
