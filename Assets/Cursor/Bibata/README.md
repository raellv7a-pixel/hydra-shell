# Bibata "Modern" cursor source (vendored)

Vector cursor artwork for the shell's adaptive cursor template
(`Services/Theming/TemplateRegistry.qml`, id `cursor`; generated by
`Scripts/python/src/theming/cursor-generate.py`).

## Origin

Trimmed to the "Modern" shape set (left-hand only) from
[rtgiskard/bibata_cursor](https://github.com/rtgiskard/bibata_cursor)
(`svg/groups/{modern,modern-arrow,shared,hand}`), itself based on the
original hand-drawn design by
[Abdulkaiz Khatri (ful1e5)](https://github.com/ful1e5/Bibata_Cursor).

The idea of recoloring Bibata through Material Design 3's
Container/Primary roles (dark body + vibrant outline) — rather than a
single flat accent — comes from
[SakibShahariar/material-bibata-cursor](https://github.com/SakibShahariar/material-bibata-cursor).
This shell reimplements that idea natively: colors are derived live
from the shell's own generated palette instead of picking from a fixed
set of 28 presets.

## Recolor contract

Every SVG here uses three literal placeholder fills, replaced verbatim
(exact string match, no parsing) by `cursor-generate.py`:

| Placeholder | Role                                   |
|-------------|-----------------------------------------|
| `#00FF00`   | Body (dark, desaturated fill)           |
| `#0000FF`   | Outline (vibrant accent)                |
| `#FF0000`   | Watch background (busy-cursor backdrop) |

`left_ptr_watch/` and `wait/` also contain four fixed spinner-dot
colors (`#FCB813`, `#F05024`, `#7EBA41`, `#32A0DA`) that are left
untouched, matching upstream's own pipeline.
