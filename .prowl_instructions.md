# Prowl and Hydra development notes

For structural code questions, query the installed `prowl` CLI or Prowl MCP before grepping or opening multiple files.

## Bounded discovery
- `prowl overview` maps the repo; `prowl find <symbol>` locates a symbol.
- `prowl def <symbol>` reads one symbol; `prowl outline <path>` shows structure.
- `prowl references <symbol>` traces uses; `prowl impact <path>` estimates blast radius.
- `prowl search "<query>"` searches code; `prowl context search "<question>" --budget-tokens 2000` returns a bounded cited packet.
- `prowl doctor --fail-on error` checks repository structure; `prowl changed` and `prowl wip` recover current Git work.
- Use `grep` for literal text and `glob` for filenames. Keep each retrieval focused; expand the budget only when needed.

Prowl v0.16.8 is installed as `prowl`; the old `prowl-agent` executable name is not available. MCP runs `prowl serve --mcp-surface core`.

## Truth and memory
Git/working tree is authoritative for code. Beads is operational work state. Sharpshooter is for durable decisions. Prowl Knowledge is for accepted, code-evidenced facts. Never let memory override current repository evidence.
