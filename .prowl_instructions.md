# Instruções de Uso do Prowl Agent & Convenções da Hydra Shell

Para o projeto Hydra Shell (`/home/raell/Projetos/hydra-shell`), SEMPRE utilize o `prowl-agent` para navegação, busca e inteligência de código antes de ler arquivos inteiros.

## Comandos Principais
- `prowl-agent overview`: Mapa completo do projeto, subsistemas, clusters e pontos de entrada.
- `prowl-agent find <nome>`: Localiza assinaturas de símbolos, funções, componentes e linhas.
- `prowl-agent search <texto>`: Busca por significado, texto ou padrões com suporte a `--smart` ou `--compact`.
- `prowl-agent callers <path>`: Identifica o que importa ou chama um arquivo.
- `prowl-agent callees <path>`: Identifica dependências de um arquivo.
- `prowl-agent impact <path>`: Raio de impacto antes de alterar/deletar um arquivo.
- `prowl-agent references <id>`: Locais de uso de um símbolo.
- `prowl-agent clusters [nome]`: Lista subsistemas e arquivos pertencentes.
- `prowl-agent doctor`: Diagnóstico do projeto (chaves duplicadas, refs quebradas).
- `prowl-agent changed`: Mapeia alterações git aos arquivos afetados.

## Diretriz de Execução
Ao trabalhar neste repositório:
1. Consultar a estrutura e símbolos via `prowl-agent` no shell antes de realizar modificações.
2. Abrir arquivos brutos somente nas linhas indicadas pelas consultas do `prowl-agent`.
3. **Idioma Obrigatório (pt_BR)**: Todos os novos recursos, abas de configuração, textos de interface, labels, tooltips e menus adicionados à Hydra Shell DEVEM estar em português brasileiro nativo (pt_BR), com vocabulário natural e amigável.
